The goal of this lab is to build an interactive Android screen that demonstrates Spinner with custom ArrayAdapters, stable IDs for reliable selection tracking, independent checkbox preferences in dropdown items, and lifecycle state restoration across rotation. By the end of this lab the app can:

3· Key Concept: Adapter vs. Source Collection

💡 Critical distinction: The source collection (List) is separate from the adapter. The adapter is a view transformer — it takes domain objects and creates/inflates Views for the Spinner. The adapter manages:
  • View recycling (convertView pattern via ViewHolder)
  • Binding domain data to specific view layouts (row vs dropdown)
  • The prompt item (position 0) separately from valid choices
  • Stable IDs via getItemId() for reliable selection tracking
┌─────────────────────────────────────────────────────────────────┐ │ DATA FLOW IN SPINNER ADAPTER │ ├─────────────────────────────────────────────────────────────────┤ │ │ │ List (source) │ │ │ │ │ ▼ │ │ ┌─────────────────────┐ │ │ │ MushroomAdapter │ ◄── Manages: │ │ │ extends ArrayAdapter│ • View recycling (ViewHolder) │ │ │ │ • Row layout (getView) │ │ │ - rowLayoutRes │ • Dropdown layout (getDropDownView)│ │ │ - dropdownLayoutRes│ • Prompt at position 0 │ │ │ - hasStableIds() │ • Stable IDs (getItemId) │ │ └──────────┬──────────┘ │ │ │ │ │ ┌─────┴─────┐ │ │ ▼ ▼ │ │ getView() getDropDownView() │ │ (closed) (expanded) │ │ │ │ │ │ ▼ ▼ │ │ Spinner Dropdown │ │ button list │ │ │ └─────────────────────────────────────────────────────────────────┘

Why Stable IDs Matter

Without stable IDs, selection is tracked by position. If the list reorders (sort, filter, reverse), the item at position 3 might become a different mushroom. With stable IDs:

  • getItemId(position) returns the domain object's ID hash (e.g., "agaricus_bisporus".hashCode())
  • hasStableIds() returns true
  • On rotation or reorder, findPositionById(adapter, selectedId) finds the correct position
  • Selection persists correctly even if list order changes
💡 Demo: Call simulateReorderList() to reverse the list — the selection stays on the same mushroom because it's tracked by stable ID, not position.

5.1 MushroomType

Immutable domain model with stable ID (scientific name), implements Parcelable for potential bundle/intent passing.

MushroomType.java · core fields
public class MushroomType implements Parcelable {

    @NonNull private final String id;          // Stable identifier (scientific name)
    @NonNull private final String commonName;  // Display label
    @NonNull private final String scientificName;
    private final boolean isEdible;   // Domain property
    @NonNull private final String notes;

    // Constructor, Parcelable impl, getters...

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof MushroomType)) return false;
        MushroomType that = (MushroomType) o;
        return id.equals(that.id); // Equality by stable ID
    }

    @Override
    public int hashCode() {
        return id.hashCode();
    }

    @Override
    public String toString() {
        return commonName; // Default display for ArrayAdapter
    }
}

6· Custom Adapters

6.1 MushroomAdapter

Extends ArrayAdapter with custom row/dropdown layouts, stable IDs, and checkbox listener.

MushroomAdapter.java · stable IDs
@Override
public long getItemId(int position) {
    // Position 0 is the prompt - return NO_ID
    if (position == 0) {
        return AdapterView.NO_ID;
    }
    // Return stable ID from domain object (scientific name hash)
    MushroomType item = getItem(position);
    return item != null ? item.getId().hashCode() : AdapterView.NO_ID;
}

@Override
public boolean hasStableIds() {
    return true; // Critical: enables reliable selection restoration
}
MushroomAdapter.java · getView (closed state)
@NonNull @Override
public View getView(int position, @Nullable View convertView, @NonNull ViewGroup parent) {
    ViewHolder holder;
    if (convertView == null) {
        convertView = inflater.inflate(rowLayoutRes, parent, false);
        holder = new ViewHolder(convertView);
        convertView.setTag(holder);
    } else {
        holder = (ViewHolder) convertView.getTag();
    }

    MushroomType mushroom = getItem(position);
    if (mushroom != null) {
        holder.nameText.setText(mushroom.getCommonName());
        holder.scientificText.setText(mushroom.getScientificName());
        // Hide checkbox in closed state - it's only in dropdown
        holder.edibleCheckBox.setVisibility(View.GONE);
    } else {
        // Prompt item
        holder.nameText.setText(getContext().getString(R.string.prompt_select_mushroom));
        holder.scientificText.setText("");
        holder.edibleCheckBox.setVisibility(View.GONE);
    }
    return convertView;
}
MushroomAdapter.java · getDropDownView (expanded state)
@Override
public View getDropDownView(int position, @Nullable View convertView, @NonNull ViewGroup parent) {
    DropDownViewHolder holder;
    if (convertView == null) {
        convertView = inflater.inflate(dropdownLayoutRes, parent, false);
        holder = new DropDownViewHolder(convertView);
        convertView.setTag(holder);
    } else {
        holder = (DropDownViewHolder) convertView.getTag();
    }

    MushroomType mushroom = getItem(position);
    if (mushroom != null) {
        holder.nameText.setText(mushroom.getCommonName());
        holder.scientificText.setText(mushroom.getScientificName());
        holder.notesText.setText(mushroom.getNotes());

        // Checkbox for non-sensitive preference (edible marking)
        // INDEPENDENT of Spinner selection:
        // - Selection chooses ONE mushroom (radio-like behavior)
        // - Checkbox is a per-item preference that doesn't affect selection
        holder.edibleCheckBox.setText(R.string.checkbox_edible);
        holder.edibleCheckBox.setChecked(mushroom.isEdible());
        holder.edibleCheckBox.setOnCheckedChangeListener(null); // Clear old listener
        holder.edibleCheckBox.setOnCheckedChangeListener((buttonView, isChecked) -> {
            if (edibleToggleListener != null) {
                edibleToggleListener.onEdibleToggled(mushroom, isChecked);
            }
        });
        holder.edibleCheckBox.setVisibility(View.VISIBLE);
    } else {
        // Prompt item - disable and style differently
        holder.nameText.setText(getContext().getString(R.string.prompt_select_mushroom));
        holder.scientificText.setText("");
        holder.notesText.setText("");
        holder.edibleCheckBox.setVisibility(View.GONE);
        convertView.setEnabled(false);
        convertView.setAlpha(0.5f);
    }
    return convertView;
}

7.4 setupAdapters: Build Adapters with Prompt

MainActivity.java · setupAdapters & rebuildSpinnerData
private void setupAdapters() {
    mushroomAdapter = new MushroomAdapter(
            this, R.layout.spinner_row_mushroom, R.layout.spinner_dropdown_mushroom,
            new ArrayList<>() // Start empty, we'll add prompt + items
    );
    mushroomAdapter.setOnEdibleToggleListener((mushroom, isChecked) -> {
        mushroomEdiblePreference = isChecked;
        Toast.makeText(this, "Edible preference for " + mushroom.getCommonName() + ": " + isChecked,
                Toast.LENGTH_SHORT).show();
    });

    collectionAdapter = new CollectionPointAdapter(
            this, R.layout.spinner_row_collection, R.layout.spinner_dropdown_collection,
            new ArrayList<>()
    );
    collectionAdapter.setOnCollectedToggleListener((point, isChecked) -> {
        collectionCollectedPreference = isChecked;
        Toast.makeText(this, "Collected status for " + point.getName() + ": " + isChecked,
                Toast.LENGTH_SHORT).show();
    });

    // Add prompt item (position 0) + data items
    rebuildSpinnerData();

    spinnerMain.setAdapter(showingMushrooms ? mushroomAdapter : collectionAdapter);
}

/**
 * Rebuilds spinner data with prompt at position 0.
 * This demonstrates: adapter manages prompt separately from valid choices.
 */
private void rebuildSpinnerData() {
    if (showingMushrooms) {
        mushroomAdapter.clear();
        // Add prompt as first item (null = prompt)
        mushroomAdapter.add(null);
        // Add actual data
        for (MushroomType m : mushroomList) {
            mushroomAdapter.add(m);
        }
        // Restore selection by stable ID
        if (selectedMushroomId != null) {
            int pos = findPositionById(mushroomAdapter, selectedMushroomId);
            if (pos > 0) {
                spinnerMain.setSelection(pos);
                selectedMushroomPosition = pos;
            } else {
                // Previously selected item no longer available
                selectedMushroomId = null;
                selectedMushroomPosition = 0;
                spinnerMain.setSelection(0);
            }
        }
        updateEmptyState(mushroomList.isEmpty());
    } else {
        // Same pattern for collection points...
    }
    mushroomAdapter.notifyDataSetChanged();
    collectionAdapter.notifyDataSetChanged();
}

7.5 Selection Listener: Track by Stable ID

MainActivity.java · onItemSelectedListener
private void setupListeners() {
    spinnerMain.setOnItemSelectedListener(new AdapterView.OnItemSelectedListener() {
        @Override
        public void onItemSelected(AdapterView parent, View view, int position, long id) {
            // Ignore prompt selection (position 0 or NO_ID)
            if (position == 0 || id == AdapterView.NO_ID) {
                clearSelection();
                return;
            }

            if (showingMushrooms) {
                MushroomType selected = mushroomAdapter.getItem(position);
                if (selected != null) {
                    selectedMushroomId = selected.getId();      // Store STABLE ID
                    selectedMushroomPosition = position;        // Store position for display
                    updateConfirmationView();
                }
            } else {
                CollectionPoint selected = collectionAdapter.getItem(position);
                if (selected != null) {
                    selectedCollectionId = selected.getId();    // Store STABLE ID
                    selectedCollectionPosition = position;
                    updateConfirmationView();
                }
            }
        }

        @Override
        public void onNothingSelected(AdapterView parent) {
            clearSelection();
        }
    });

    // Mode switch button
    btnSwitchMode.setOnClickListener(v -> {
        showingMushrooms = !showingMushrooms;
        btnSwitchMode.setText(showingMushrooms ?
                R.string.btn_switch_mode : R.string.btn_switch_mode_mushroom);
        tvEmptyState.setText(showingMushrooms ?
                R.string.empty_list_mushroom : R.string.empty_list_collection);

        // Swap adapter
        spinnerMain.setAdapter(showingMushrooms ? mushroomAdapter : collectionAdapter);
        rebuildSpinnerData();
        updateConfirmationView();
    });
}

7.6 State Restoration: onSaveInstanceState & restoreState

MainActivity.java · onSaveInstanceState
@Override
protected void onSaveInstanceState(@NonNull Bundle outState) {
    super.onSaveInstanceState(outState);
    outState.putBoolean(KEY_SHOWING_MUSHROOMS, showingMushrooms);
    outState.putString(KEY_SELECTED_MUSHROOM_ID, selectedMushroomId);
    outState.putString(KEY_SELECTED_COLLECTION_ID, selectedCollectionId);
    outState.putInt(KEY_SELECTED_MUSHROOM_POS, selectedMushroomPosition);
    outState.putInt(KEY_SELECTED_COLLECTION_POS, selectedCollectionPosition);
    outState.putBoolean(KEY_MUSHROOM_EDIBLE, mushroomEdiblePreference);
    outState.putBoolean(KEY_COLLECTION_COLLECTED, collectionCollectedPreference);
}
MainActivity.java · restoreState
private void restoreState(@NonNull Bundle savedInstanceState) {
    showingMushrooms = savedInstanceState.getBoolean(KEY_SHOWING_MUSHROOMS, true);
    selectedMushroomId = savedInstanceState.getString(KEY_SELECTED_MUSHROOM_ID);
    selectedCollectionId = savedInstanceState.getString(KEY_SELECTED_COLLECTION_ID);
    selectedMushroomPosition = savedInstanceState.getInt(KEY_SELECTED_MUSHROOM_POS, 0);
    selectedCollectionPosition = savedInstanceState.getInt(KEY_SELECTED_COLLECTION_POS, 0);
    mushroomEdiblePreference = savedInstanceState.getBoolean(KEY_MUSHROOM_EDIBLE, false);
    collectionCollectedPreference = savedInstanceState.getBoolean(KEY_COLLECTION_COLLECTED, false);

    btnSwitchMode.setText(showingMushrooms ?
            R.string.btn_switch_mode : R.string.btn_switch_mode_mushroom);
}
💡 Note: We store stable IDs (strings) not positions. On restore, rebuildSpinnerData() calls findPositionById() to find the current position of the previously selected item. This works even if the list was reordered!

10· Lifecycle Trace & Explanation

Predicted vs observed lifecycle sequence for each case:

Scenario Predicted Sequence Observed (Logcat) Explanation
Cold launch onCreate → onStart → onResume Matches Fresh process, no savedInstanceState, default state (mushroom mode, no selection)
Rotation onPause → onStop → onSaveInstanceState → onDestroy → onCreate → onStart → onResume Matches Activity recreated; savedInstanceState non-null → restoreState() called → rebuildSpinnerData() restores selection by stable ID
Mode switch onClick → setAdapter → rebuildSpinnerData Matches No lifecycle events; just adapter swap. Per-mode state (selection IDs, checkbox prefs) preserved in fields.
Process restart (swipe from recents) onPause → onStop → onDestroy → (process dies) → onCreate → onStart → onResume Matches New process, savedInstanceState is null → all state reset to defaults

What survives what?

  • Mode (showingMushrooms): saved in onSaveInstanceState → survives rotation, process restart loses it.
  • Selection (stable IDs): saved in onSaveInstanceState → survives rotation; restored via findPositionById() in rebuildSpinnerData().
  • Checkbox preferences: saved in onSaveInstanceState → survives rotation.
  • Per-mode state: Both modes maintain independent selection IDs and checkbox states in fields — switching modes doesn't lose the other mode's state.
  • In-memory domain lists: Survive rotation (process alive); do not survive process restart.
⚠ Key distinction: Stable IDs allow selection to survive reordering within the same process. They do not survive process death — for that you'd need persistent storage (Room, SharedPreferences). This lab demonstrates in-memory state management only.

11· Design Choices, Corrections, Limitations

Design Choice 1: Custom ArrayAdapter (not RecyclerView)

Reasoning: Spinner is the appropriate widget for single-choice dropdown selection. RecyclerView would be overkill and doesn't provide the native dropdown UX. ArrayAdapter with custom layouts demonstrates the adapter pattern cleanly.

Design Choice 2: Stable IDs via domain object ID hash

Reasoning: Using item.getId().hashCode() in getItemId() with hasStableIds() = true is the standard Android pattern for reliable selection. The domain models implement equals()/hashCode() by ID for consistency.

Design Choice 3: Independent checkboxes in dropdown

Reasoning: Demonstrates that list item interactions ≠ selection. The checkbox is a per-item preference (metadata), while Spinner enforces single-choice. This mirrors real-world patterns like "mark as favorite" or "mark as read" alongside a primary selection.

Defect Corrected: Prompt item handling

Original bug: Early version treated prompt as selectable item, causing crashes when getItem(position) returned null. Correction: Prompt added as null at position 0; getItemId(0) returns NO_ID; onItemSelected ignores position 0 and NO_ID; prompt disabled and styled at 50% alpha in dropdown.

Limitation: No persistent storage

All state (selections, checkboxes, mode) is in-memory and survives only rotation (via Bundle), not process restart. In a production app, selections and preferences would be persisted to Room/SharedPreferences and observed via LiveData/Flow.

Limitation: Checkbox state not visually restored in dropdown

The checkbox preference is saved/restored in the Activity field and shown via Toast, but the dropdown ViewHolder doesn't re-read the preference when recycled. A full implementation would store preferences in the domain model or a separate map and bind in getDropDownView().

12· Relation to Real-World Apps

  • Settings screens: Spinner for single-choice settings (theme, language, sort order) with stable IDs so selection survives config changes.
  • Forms with dependent dropdowns: Country → State/Province spinners where stable IDs ensure correct cascading selection.
  • Product variant selection: Size/color spinners in e-commerce — stable IDs map to SKU.
  • Filter/sort controls: Toolbar spinners where selection persists across navigation.
  • Metadata tagging: Checkboxes in dropdowns for "mark as favorite", "mark as read", "archive" — independent of primary selection.
